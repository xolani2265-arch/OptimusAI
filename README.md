# Optimus AI

Android gold/XAUUSD analysis assistant foundation.

Version 1.2 includes:
- R550 risk-first account model
- encrypted persistent trade journal using Android Keystore + AES-GCM
- basic trade performance view
- diagnostics and controlled-recovery guardrails
- mobile Compose UI
- GitHub Actions cloud APK build

Live market providers, secure AI backend, screenshot vision, and broker execution remain separate integrations. No API secret is embedded in the APK.

The app does not guarantee profitable trades and does not perform unrestricted self-modifying code.
